# 파일 권한 바로잡기

`~/shell-lab/secret.txt` 에 다른 사용자가 보면 안 되는 내용이 들어 있습니다.
그런데 파일이 모두에게 읽기 권한으로 만들어졌습니다.

## 목표

- `secret.txt` 를 소유자 `lab` 만 읽고 쓸 수 있게 바꿉니다.
- 파일 내용과 소유자는 바꾸지 않습니다.

## 관찰

```bash
ls -l ~/shell-lab
stat -c '%a %U %n' ~/shell-lab/secret.txt
```

권한 문자열은 세 글자씩 소유자, 그룹, 기타 사용자의 권한입니다.

## 확인

고친 뒤 패널의 **확인** 버튼을 누르세요. 확인 스크립트는 권한, 소유자, 내용을 함께 봅니다.
