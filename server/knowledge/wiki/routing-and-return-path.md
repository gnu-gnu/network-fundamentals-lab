# 라우팅과 왕복 경로

## 경로 선택과 통신 성공

라우터는 목적지 IP와 가장 길게 일치하는 접두사의 경로를 선택한다. 더 구체적인 블랙홀
경로는 넓은 범위의 정상 연결 경로보다 우선할 수 있다. 같은 서브넷의 인접 주소가 된다는
사실만으로 문제 목적지에 같은 경로가 선택된다고 판단하면 안 된다.

요청이 목적지까지 도달하더라도 응답 경로가 없으면 ping이나 TCP 연결은 실패한다.
04장에서는 r1의 목적지 대역 경로와 r2의 클라이언트 대역 리턴 경로를 나란히 비교한다.
라우팅 테이블은 설정 증거이며, 실제 패킷 도달의 직접 증거와는 구분한다.

## TTL과 동적 라우팅

상호 기본 경로는 모르는 목적지를 서로에게 돌려보내는 루프를 만들 수 있다. TTL은 이
패킷의 무한 순환을 제한하지만 잘못된 경로를 고치지는 않는다. 06장은 존재하지 않는 외부
호스트의 ping을 성공시키는 대신 루프를 명시적인 도달 불가로 바꾸는 실습이다.

OSPF의 인접 관계와 경로 학습, BGP의 세션 성립과 접두사 광고는 각각 다른 확인 대상이다.
세션이 Established라고 해서 필요한 모든 경로가 광고되었다고 판단하면 안 된다.
